# Тесты

Скрипты гоняются во **временной папке** с копией тестовых фикстур
(`test/fixtures/`: свои `recipes/`, `translations/` и `settings.cfg`),
поэтому ваш `settings.cfg`, `recipes/` и `translations/`
не изменяются, а результат тестов не зависит от скачанных данных.
Скачивать что-то перед запуском не нужно.

Команды ниже используют окружение `.venv`, которое создаёт `./run.sh`
(если запускаете тесты внутри активированного окружения, достаточно
просто `python`).

## Сквозной тест интерфейса

Проверяет старт, поиск (подсказки, клик, Enter), стили выпадающих попапов
(тёмный фон у списка комбобокса, попапа подсказок и меню выбора рецепта),
расчёт с отступами по
глубинам рекурсии (цепочка Альфа→Бета→Гамма→Дифенгидрамин из фикстур),
разворот рецептуры катализатора (серная кислота в рецепте Дифенгидрамин),
оверлей (перетаскивание, ресайз по 8 направлениям,
прозрачность), настройки (цвета, язык, таблица ссылок с режимами
рецептов/переводов, категориями, колонкой локальных файлов, сброс),
пресеты (ссылки из `data.BUILTIN_PRESETS` с проверкой их формата,
сохранение/загрузка с авто-бэкапом в `backup` и перекачкой файлов через
стандартное обновление, переименование, удаление, конвертация старого
формата) и поток обновления.

```bash
python test/test_app.py                        # с дисплеем
QT_QPA_PLATFORM=offscreen python test/test_app.py   # без дисплея
```

Код `0` — все проверки прошли, `1` — есть падения (они перечислены в конце).

## Снимок расчёта

Дампит отрисованный результат для **всех** рецептов-фикстур (глубокая
цепочка, катализатор, рецепт с id на Drink) — детерминированно и независимо
от скачанных данных. Удобно для сравнения до/после изменений:

```bash
python test/snapshot_calculation.py > /tmp/after.txt
diff /tmp/before.txt /tmp/after.txt
```

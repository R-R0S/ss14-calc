# Тесты

Скрипты гоняются в **временной папке** с копией скачанных данных, поэтому
ваш `settings.cfg`, `recipes/` и `translations/` не изменяются.

Перед первым запуском скачайте данные: запустите приложение и нажмите
`Обновить данные`.

Команды ниже используют окружение `.venv`, которое создаёт `./run.sh`
(если запускаете тесты внутри активированного окружения, достаточно
просто `python`).

## Сквозной тест интерфейса

Проверяет старт, поиск (подсказки, клик, Enter), расчёт с отступами по
глубинам рекурсии, разворот рецептуры катализатора (серная кислота в
`RobustHarvest`), оверлей (перетаскивание, ресайз по 8 направлениям,
прозрачность), настройки (цвета, язык, ссылки, сброс) и поток обновления.

```bash
python test/test_app.py                        # с дисплеем
QT_QPA_PLATFORM=offscreen python test/test_app.py   # без дисплея
```

Код `0` — все проверки прошли, `1` — есть падения (они перечислены в конце).

## Снимок расчёта

Дампит отрисованный результат для выборки рецептов — удобно для сравнения
до/после изменений:

```bash
python test/snapshot_calculation.py > /tmp/after.txt
diff /tmp/before.txt /tmp/after.txt
```

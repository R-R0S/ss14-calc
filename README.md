# SS14 Химический калькулятор 🧪
Калькулятор для расчета реагентов в игре **Space Station 14**

[![GitHub release](https://img.shields.io/github/v/release/R-R0S/ss14-calc?include_prereleases&style=for-the-badge)](https://github.com/R-R0S/ss14-calc/releases/latest)
[![License](https://img.shields.io/github/license/R-R0S/ss14-calc?style=for-the-badge)](LICENSE)


![screenshot1](https://github.com/R-R0S/ss14-calc/blob/main/img/screenshot1.png?raw=true)


## 🌟 Особенности
- Расчет цепочек реакций с глубиной вложенности
- Оверлей поверх игрового окна
- Автоматическое обновление рецептов и переводов из репозиториев SS14
- Лёгкое добавление собственных рецептов (локально или с GitHub)
- Автоматическая проверка обновлений
- Поддержка рецептов электролиза, центрифуги и смешивания напитков
- Лёгкий поиск рецептов через поисковую строку
- Вы можете скрывать рецепты в реакции или выбирать альтернативные просто кликнув по ним


### 📥 Установка (Windows)
* Для windows скачайте ss14-calc.exe из последнего релиза:
[▶️ Последний релиз](https://github.com/R-R0S/ss14-calc/releases/latest)
- после запуска приложение создаст каталоги для рецептов, переводов и пресетов, а так же файл настроек.


### 🎮 Использование
* После запуска зайдите в настройки - Данные - Пресеты
* Выберите пресет для вашего сервера и нажмите "Загрузить"
* Можете закрывать настройки и пользоваться калькулятором

```🔄 Обновить данные ``` - Обновление рецептов и переводов, ссылки указываются в настройках

```🖥️ Показать/скрыть️ Оверлей``` - Включает оверлей с рецептами

```⚙️ Настройки``` -  Настройки, изменяйте прозрачность оверлея, цветов в рекурсии, добавляйте свои рецепты, переводы и пресеты.


### 🐧 Запуск из исходников (Linux)
1. Клонируйте репозиторий:
```bash
git clone https://github.com/R-R0S/ss14-calc.git
cd ss14-calc
```
2. Запустите скрипт — он сам проверит Python, создаст окружение `.venv`,
   установит зависимости и откроет калькулятор:
```bash
./run.sh
```

То же самое вручную, без скрипта:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```


### 📦 Требования
* Python 3.10+ (проверено на 3.12 и 3.14)


### 🛠️ Использование оверлея
1. В игре включите Оконный режим
2. Запустите калькулятор и нажмите ```🖥️ Показать оверлей```
3. Перетащите окно оверлея в нужную позицию, задайте размер
4. Теперь в оверлее будет дублироваться рецепт из основного окна
5. Прозрачность оверлея можно изменить в настройках (Вы так же можете прокручивать оверлей колёсиком мыши)
6. Реактанты в оверлее тоже кликабельные, скрывайте рецепты того, что уже готово или выбирайте альтернативные рецепты.

 Настройки > О приложении > Сбросить все настройки.
 * Если сброс не помог - можете написать мне в [дискорд](https://discord.com/users/317692089355862016) или в [issue](https://github.com/R-R0S/ss14-calc/issues) на GitHub
 * Возможно, антивирус будет ругаться на `.exe` файл. В таком случае удалите ваш антивирус. (или добавьте файл/рабочую папку в исключения антивируса)
